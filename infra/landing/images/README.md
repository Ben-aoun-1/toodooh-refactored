# Images

## Hero Section

Placez l'image du restaurant avec les écrans TV dans ce dossier avec le nom :

**restaurant-hero.jpg** (ou .png)

### Instructions

1. Exportez l'image depuis Figma
2. Nommez-la `restaurant-hero.jpg` (ou `.png`)
3. Placez-la dans ce dossier : `public/images/`
4. L'image sera automatiquement chargée dans la section Hero

## Section Annonceurs

Placez l'image de la personne en costume tenant un smartphone avec le nom :

**annonceurs-hero.jpg** (ou .png)

### Instructions

1. Exportez l'image depuis Figma
2. Nommez-la `annonceurs-hero.jpg` (ou `.png`)
3. Placez-la dans ce dossier : `public/images/`
4. L'image sera automatiquement chargée dans la section Annonceurs

### Formats acceptés
- JPG / JPEG
- PNG
- WebP

### Recommandations
- Taille optimale : 1440px - 1920px de largeur
- Ratio recommandé : 16:10 ou similaire
- Qualité : Exportez en @2x depuis Figma pour les écrans haute résolution
