# Clash Grotesk Font Files

Ce dossier doit contenir les fichiers de police Clash Grotesk au format `.woff2`.

## Fichiers requis :

- `ClashGrotesk-Regular.woff2` (font-weight: 400)
- `ClashGrotesk-Medium.woff2` (font-weight: 500) - **Requis pour "Smarter ads. Real impact."**
- `ClashGrotesk-SemiBold.woff2` (font-weight: 600)
- `ClashGrotesk-Bold.woff2` (font-weight: 700)
- `ClashGrotesk-ExtraBold.woff2` (font-weight: 800)

## Installation

Placez les fichiers `.woff2` de Clash Grotesk dans ce dossier avec les noms exacts ci-dessus.

Les règles `@font-face` sont déjà configurées dans `src/styles/index.css`.
